# John Billgates R. Marquinez — Portfolio

A responsive personal portfolio built with **HTML, CSS, and JavaScript** for Visual Studio Code.

## How to open it
1. Extract `John_Billgates_Portfolio.zip`.
2. Open the extracted `John_Billgates_Portfolio` folder in Visual Studio Code.
3. Open `index.html` in a browser. Recommended: install the **Live Server** extension in VS Code, right-click `index.html`, then choose **Open with Live Server**.
4. Keep the `assets` folder beside `index.html`, `style.css`, and `script.js`.

## What's included
- Responsive dark tech-inspired design
- About, motto, academic achievements, Mobile Legends profile, hobbies, photo gallery, and social links
- Click-to-expand photo gallery
- Copy button for Mobile Legends player ID
- Small hidden note: click the ✳ in the footer three times, or type `riam` on the page

## Edit your details
- Main content and links: `index.html`
- Colors, layout, fonts, responsive styling: `style.css`
- Interactive features: `script.js`
- Photos: replace images in `assets` while keeping the same filenames, or update the image paths in `index.html`.

## Photo note
The five images from the uploaded ZIP are copied into `assets` as `photo-1.png` through `photo-5.png`. The page uses them in the portrait, gallery, gaming, and hobbies sections. Replace them with your preferred photos whenever you are ready.

## Small privacy note
The hidden “chrushie cakes” note is a playful front-end easter egg, not secure or private. Anyone who inspects the website files can discover it.
